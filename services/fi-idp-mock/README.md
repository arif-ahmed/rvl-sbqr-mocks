# fi-idp-mock

A mock implementation representing a Financial Institution's Identity
Provider for SBQR development and integration testing.

Its eventual responsibilities may include simulated authentication,
token issuance, identity claims, invalid-token scenarios, and related
IdP behaviour.

> Scaffolding only — none of these capabilities are implemented yet.
> The `src/` directory is intentionally empty and the `Dockerfile` is
> a placeholder. The runtime, language, and framework for this service
> have not been chosen.
