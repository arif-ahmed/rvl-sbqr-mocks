# bb-trust-store-mock

A mock implementation representing the Bangladesh Bank trust-store
integration used for SBQR development and integration testing.

Its eventual responsibilities may include exposing mock public keys,
certificates, trust metadata, key rotation scenarios, and error
scenarios.

> Scaffolding only — none of these capabilities are implemented yet.
> The `src/` directory is intentionally empty and the `Dockerfile` is
> a placeholder. The runtime, language, and framework for this service
> have not been chosen.
