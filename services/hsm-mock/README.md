# hsm-mock

A mock implementation representing HSM-related functionality for SBQR
development and integration testing.

Its eventual responsibilities may include simulated signing,
verification, key references, and controlled cryptographic test
scenarios.

> This mock must never be treated as a real HSM or production-grade
> key-protection mechanism. It exists only to support development and
> integration testing.

> Scaffolding only — no cryptographic functionality is implemented yet.
> The `src/` directory is intentionally empty and the `Dockerfile` is
> a placeholder. The runtime, language, and framework for this service
> have not been chosen.
